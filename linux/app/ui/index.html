Connect Claude

LimitFuel reads your claude.ai session from Chrome, Chromium or Brave. It only reads claude.ai cookies, and never writes to your browser.

On Windows, paste your claude.ai cookie. Chrome 127 and later encrypt cookies so that only the browser itself can read them (App-Bound Encryption), and browsers keep their cookie file locked while they run. LimitFuel doesn’t work around either, so browser detection usually finds nothing here.

Paste a cookie instead

In your browser’s developer tools, copy the Cookie request header from any claude.ai request. It is kept in your keyring, not in a file.

In Chrome or Edge, open claude.ai and press F12. In the Network tab, reload the page, select any request to claude.ai and copy the value of its Cookie request header. LimitFuel keeps it in Windows Credential Manager, not in a file.
